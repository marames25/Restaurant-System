# Restaurant-System

A Java-based restaurant management system demonstrating object-oriented design and restaurant ordering logic.

## Description
This project contains a Java application centered around `RestaurantFacade` and includes menu, ordering, payment, discount, and observer logic.

## Features
- menu management
- food item and meal modeling
- ordering flow
- discount handling
- payment processing
- observer-based service interaction
- modular architecture

## Technologies Used
- Java
- Object-oriented programming

## Prerequisites
- Java JDK
- Terminal or IDE such as IntelliJ IDEA

## Installation
```bash
javac -d out $(find src -name "*.java")
```

## How to Run
```bash
java -cp out Main
```

## Project Structure
- `src/Main.java`
- `src/restaurant/app/`
- `src/restaurant/items/`
- `src/restaurant/menu/`
- `src/restaurant/ordering/`
- `src/restaurant/payment/`
- `src/restaurant/discount/`
- `src/restaurant/observer/`

## Notes
The repository is organized as a Java application and separates menu, ordering, payments, and observer logic.
